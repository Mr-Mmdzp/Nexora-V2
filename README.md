
# Nexora V2

Nexora V2 is a dark-themed PC hardware e-commerce website built with HTML, CSS and JavaScript.

The main goal of this project was to practice building a complete front-end experience with dynamic data, interactive UI elements and JavaScript functionality.
## 🌐 Demo 
[✨Lunch Demo 👆](https://mr-mmdzp.github.io/NexusV2/)
## 🚀 Features

- 🛒 Shopping cart system
- 📦 Inventory popup
- 🔍 Product search
- 🖼️ Image slider
- ➕ Add-to-cart animations
- ✨ Product highlight animation
- 🎨 Dark Obsidian + Electric Violet UI
- 🖥️ Dynamic product rendering using `database.json`
- 🎯 Interactive product cards
- 🌌 Canvas particle and connection effects
- ⚡ JavaScript-powered interactions
- 📱 **Responsive design was NOT a goal of this project**

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- JSON
- Canvas API

## 🎨 Design & Inspiration

The original source of the product images and the main design inspiration for this project was **PCMod**.

I used images from PCMod and took inspiration from its overall concept and presentation while building my own implementation and functionality.

All coding and implementation of Nexora V2 was done as a personal front-end development project.

> Credit: PCMod — used as the visual/content source and inspiration for this project.

## 📌 Project Goal

Nexora V2 was created primarily as a **front-end development practice project**.

The goal was to focus on:

- JavaScript functionality
- DOM manipulation
- Dynamic content
- UI interactions
- CSS animations
- Product systems
- Working with JSON data
- Building a complete website from scratch

**Responsive design was intentionally not part of the project goal.**

A separate project will be used to focus specifically on responsive web design.
